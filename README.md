## 🧠 My Process

I built this project using a clean, component‑based approach:

- Started with semantic HTML structure  
- Added global layout and centered the card using Flexbox  
- Styled the card with spacing, typography, and color variables  
- Implemented hover and focus states for accessibility  
- Added a wrapper to properly center the attribution  
- Imported the Inter font with weights 400, 600, and 700  
- Polished spacing, rhythm, and micro‑interactions
